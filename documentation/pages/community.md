# Community

## Support

If you have an issue using sql_exporter, please check
[Discussions](https://github.com/burningalchemist/sql_exporter/discussions) or closed
[Issues](https://github.com/burningalchemist/sql_exporter/issues?q=is%3Aissue+is%3Aclosed) first. Chances are someone
else has already encountered the same problem and there is a solution. If not, feel free to create a new discussion.
